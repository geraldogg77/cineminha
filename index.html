Som dos appsEscolha programa por programa

     

      

      

       
Para escolher os apps, como Spotify, Discord e jogos, instale o Cineminha Áudio: um programa de 650 KB para Windows 10 e 11 que fica na bandeja, perto do relógio.

       
Baixar Cineminha Áudio

       Abra o arquivo baixado. Se o Windows avisar que protegeu o computador, clique em Mais informações › Executar assim mesmo. Se o navegador pedir acesso a dispositivos locais, clique em Permitir.

Sem o Cineminha Áudio: usar um cabo virtual
    
Se não puder instalar o Cineminha Áudio, dá para separar os apps com um cabo de áudio virtual:

    
  1. Instale o VB-CABLE, que é gratuito (vb-audio.com/Cable), e reinicie o computador.
    2. 
     
  2. No Windows, abra Configurações › Sistema › Som › Mixer de volume e, em cada app que deve ir para a transmissão, troque a saída para CABLE Input.
    3. 
     
  3. Aqui, ligue a Entrada extra, escolha CABLE Output e desligue o Som da tela para o som não sair duplicado.
    4. 
     
  4. Para continuar ouvindo esses apps, abra o Painel de som do Windows › Gravação › CABLE Output › Propriedades › Escutar, marque “Escutar este dispositivo” e escolha seu fone.

Privacidade
   
   
Voz, câmera e tela vão criptografadas de ponta a ponta entre os navegadores. O Cineminha não grava nem guarda nada da sala.
